# Contributing

Thanks for helping improve this site.

## What to change

**_“Like all magnificent things, it's very simple.”_**

This repo is intentionally simple, so contributions should usually stay focused
on one of these:

- Fixing content or copy.
- Improving the layout or styling.
- Updating a page, note, or asset.
- Fixing a broken link or file reference.

## Before you open a PR

- Keep the change small and easy to review.
- Check that the affected page still loads correctly.
- Avoid unrelated cleanup in the same change.

## When to open an issue first

Open an issue first if the change is large, unclear, or likely to affect more
than one page or shared file.

## Security

If your change touches a security concern, use [SECURITY.md](SECURITY.md)
instead of opening a public issue.
