# Governance

This repo is maintained in a lightweight way.

## How decisions are made

- Small changes can usually be handled through a pull request.
- Larger changes should start with an issue so the scope stays clear.
- Maintainers decide whether a change fits the repo and how it should land.

## What to expect

The goal is to keep the site simple, stable, and easy to update.
If a change adds complexity without a clear benefit, it may be declined.

**_“Keep it simple, stupid”_**

## Security and conduct

- Security reports go to [SECURITY.md](SECURITY.md).
- Conduct expectations are listed in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
