# Cost/Risk Analysis

Cost/risk analysis estimates project cost while accounting for uncertainty, tradeoffs, and possible downside.

## Core ideas

- A cost estimate is only useful if its assumptions are visible.
- Risk analysis looks at probability, impact, and mitigation.
- Sensitivity analysis shows which assumptions drive the result the most.

## Common methods and terms

- Common tools include expected value, contingency, scenario analysis, and decision trees.
- Costs are often compared over time with discounting or life-cycle thinking.
- Good analysis separates fixed costs, variable costs, and uncertain items.

## Typical questions

- Which assumption matters most?
- What is the likely downside if the estimate is wrong?
- How much contingency is justified by the uncertainty?
