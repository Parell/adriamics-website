# Kinematics

Kinematics describes motion without asking about the forces that cause it.

## Core ideas

- Position, velocity, and acceleration describe how motion changes in time.
- Graphs are as important as formulas because they show trends and sign changes.
- One-dimensional and two-dimensional motion use the same ideas with different geometry.

## Common methods and terms

- Constant-acceleration equations are useful when acceleration does not change.
- Projectile motion separates horizontal and vertical motion.
- Relative motion compares one object to another moving reference frame.

## Typical questions

- What sign convention is being used?
- Is the motion one-dimensional or two-dimensional?
- Which variable is known and which one needs to be solved for?
