# Simulation

Simulation uses a model to explore how a system behaves before the real system is built or changed.

## Core ideas

- A simulation is only as good as the assumptions built into its model.
- Deterministic and stochastic simulations answer different kinds of questions.
- Validation and sensitivity analysis show whether the model is trustworthy.

## Common methods and terms

- Common approaches include discrete-event simulation, Monte Carlo methods, and numerical time stepping.
- Random seeds, repeated trials, and scenario changes help interpret results.
- Good simulation work compares model predictions against known data.

## Typical questions

- What assumption drives the result most strongly?
- Is the model meant to predict averages, extremes, or trends?
- How do you know the simulation matches reality well enough?
