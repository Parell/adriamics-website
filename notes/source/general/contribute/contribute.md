UES is easiest to improve when each issue is small and specific. Start with one page, one request, and one short explanation.

## Ways to help

- Fix a typo or confusing sentence.
- Add one worked example.
- Add 5 practice problems.
- Review a page for correctness.
- Improve or add an interactive tool.
- Suggest a missing topic or course mapping.

## Best-fit roles

- Student user: report confusing pages or mistakes.
- Contributor: add one worked example.
- Reviewer: check one page for correctness.
- Problem writer: add 5 practice problems.
- Visual builder: improve or add an interactive tool.
- Course mapper: match pages to a course syllabus.

## What to include

- Page path, or the closest page you were reading.
- The request type, such as `needs example`, `needs practice problems`, `needs review`, `citation needed`, `bug`, or `visualization`.
- The subject tag if it applies: `calculus`, `physics`, or `engineering`.
- One short sentence explaining the change.
- A source, screenshot, or syllabus when it helps.

## Open an issue

For small edits, use [Edit this page on GitHub](https://github.com/Parell/parell.github.io/issues/new?template=contribute.yml).

For larger changes, fork the repository, create a branch, edit the relevant note file, and open a pull request.
