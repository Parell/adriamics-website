# Computational Physics

Computational physics uses algorithms and code to solve physical problems that are too difficult to handle by hand.

## Core ideas

- A physical model must be discretized before it can be computed.
- Numerical error, stability, and efficiency matter as much as the formula being used.
- Simulation and data analysis let physics problems be explored repeatedly with different assumptions.

## Common methods and terms

- Common tools include numerical integration, root finding, interpolation, and time stepping.
- Monte Carlo methods help with random or high-dimensional problems.
- Validation against analytic results or known data is part of the workflow.

## Typical questions

- What approximation was made to make the problem computable?
- Is the method stable for the chosen step size?
- How large is the numerical error?
