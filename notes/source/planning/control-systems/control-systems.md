# Control Systems

Control systems use feedback to make a process follow a desired output even when disturbances are present.

## Core ideas

- A feedback loop compares the measured output to the desired setpoint.
- Stability determines whether the system settles instead of growing without bound.
- Transfer functions and block diagrams help describe how inputs produce outputs.

## Common methods and terms

- PID control is a standard way to combine proportional, integral, and derivative action.
- Step response, overshoot, settling time, and steady-state error describe performance.
- Frequency-response tools help analyze how the system reacts to different signals.

## Typical questions

- Is the closed-loop system stable?
- How quickly does the output settle?
- What error remains after the transient response dies out?
