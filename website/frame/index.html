Frame is an open-source framework in development for defining physical systems and their intended behavior. Its design brings simulation, engineering analysis, and measurement-based digital twins into one extensible architecture.

What Frame is designed to do

Frame is intended to make it easier to define a physical system, run simulations, and use the results to guide engineering decisions.

  • Model physical systems: define spacecraft, propulsion, robotics, thermal systems, structures, and other connected components in one model.
  • Set up a simulation: describe the system, its environment, starting conditions, operations, sensors, and controls. Frame is intended to determine which physics need to run and how they interact.
  • Track units and timing: keep measurements, coordinate frames, time, and changing system state clear throughout a run.
  • Explore designs: reuse a system model to compare designs, optimize choices, run Monte Carlo studies, and check requirements.
  • Connect software and hardware: work with simulated or recorded sensor data, flight software, and external hardware interfaces.
  • Compare models with measurements: check simulation predictions against machine data and use the comparison to improve a model within a defined operating range.
  • Run software and hardware tests: support software-in-the-loop and hardware-in-the-loop workflows, including real-time runs.
  • Review and reproduce results: keep state histories, commands, events, uncertainty, diagnostics, and run settings together for inspection.
  • Run locally or offline: Frame is being designed to support installations without an internet connection. CMMC Level 2 readiness is a design objective, not a claim of compliance.
