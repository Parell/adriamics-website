# Arrow mesh

`arrow.glb` is a small, flat-shaded extruded arrow mesh created for this project. It uses core glTF 2.0 features only, so Shallot 0.10.3 can load it without optional mesh compression extensions.

- License: CC0 1.0 (public domain), dedicated to the public domain for this project.
- Bundled locally so the simulation makes no runtime request for the model.
